## 📘 نظرة عامة

يرافق هذا المشروع دورة مخصصة لـ:

* **JavaServer Faces 2 (JSF2)**
* **PrimeFaces**
* **PrimeFaces Mobile**

الهدف هو إنشاء تطبيق كامل **لإدارة المواعيد**، قابل للتكيف مع بيئات تقنية مختلفة.

هذا المستند عملي بطبيعته: فهو يعرض فقط العناصر الضرورية لإنشاء التطبيقات موضوع الدراسة.

## 🏗️ التطبيقات المطورة

تم تطوير التطبيق في البيئات التالية:

1. **JSF2 / EJB3 / JPA** على *Glassfish 3.1*
2. **JSF2 / PrimeFaces** (الإصدار الذي يدعم Ajax)
3. **JSF2 / PrimeFaces Mobile**
4. نقل كل إصدار إلى **JSF2 / Spring / JPA** على *Tomcat 7*
